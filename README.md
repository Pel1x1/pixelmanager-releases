## Что это

PixelManager работает **рядом** с официальным WB PVZ и добавляет то, чего в нём
не хватает: склад по ячейкам с фото товаров, дашборд смены в реальном времени,
историю и заметки по клиентам, мгновенный поиск, сканер, инвентаризацию и
предупреждение о клиентах с частыми отказами.

Приложение **ничего не меняет** в базе WB: оно только читает копию и никогда не
открывает рабочий файл WB PVZ. Работать с WB можно как обычно — параллельно.

| | |
|---|---|
| 📦 **Склад по ячейкам** | Карточки ячеек: телефоны клиентов, суммы, сроки хранения, фото товаров |
| 📊 **Смена онлайн** | Выдачи, отказы, возвраты, суммы, разбивка по часам, топ товаров |
| 👤 **Клиенты** | История заказов, заметки по номеру, предупреждение о проблемных |
| 🔍 **Поиск и сканер** | По ячейке, телефону, штрихкоду и названию — мгновенно |
| 🧮 **Инвентаризация** | Сканируй полки — программа сама скажет, что потеряно и что переехало |
| 🔔 **Оверлей при скане** | Заметка о клиенте всплывает поверх окна WB, не перехватывая ввод |
| 🌐 **Панель владельца** | Все точки сети, их статус и показатели — в одном веб-кабинете |

## Установка: Windows

1. Скачайте **`PixelManager_x64-setup.exe`** со [страницы релизов](https://github.com/Pel1x1/pixelmanager-releases/releases/latest).
2. Запустите файл.
3. Windows покажет синее окно **«Windows защитила ваш компьютер»** — это обычное
   предупреждение для новых программ без платной подписи Microsoft.
   Нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Готово: ярлык **PixelManager** появится в меню «Пуск» и на рабочем столе.

<details>
<summary>Антивирус ругается / файл удалён после скачивания</summary>

Некоторые антивирусы удаляют свежие неизвестные им программы «на всякий случай».
Добавьте файл в исключения антивируса и скачайте заново. Если сомневаетесь —
напишите нам, пришлём контрольную сумму файла.
</details>

<details>
<summary>Нет прав администратора на рабочем ПК</summary>

Скачайте **`PixelManager-portable-x64.exe`** и просто запустите его — установка
не требуется. Минус: такой вариант **не обновляется сам**, новую версию нужно
скачивать вручную.
</details>

## Установка: Linux

### Вариант 1 — пакет `.deb` (Debian, Ubuntu, Astra)

```bash
sudo apt install ./PixelManager_*_amd64.deb
```

`apt` сам подтянет зависимости (`libwebkit2gtk-4.1-0`, `libgtk-3-0`).
Запуск — через меню приложений, значок **PixelManager**.

### Вариант 2 — `.AppImage` (работает везде, умеет обновляться сам)

```bash
# один раз: библиотека, без которой AppImage не стартует на Debian 12
sudo apt install libfuse2

chmod +x PixelManager_*_amd64.AppImage
./PixelManager_*_amd64.AppImage
```

<details>
<summary>Ошибка «dlopen(): error loading libfuse.so.2»</summary>

Не установлена библиотека FUSE 2. Выполните `sudo apt install libfuse2`
(на Debian 12 / Ubuntu 22.04+ она не стоит по умолчанию) и запустите файл снова.
</details>

<details>
<summary>Файл не запускается двойным кликом</summary>

Нажмите правой кнопкой → **Свойства** → вкладка **Права** → поставьте галочку
**«Разрешить выполнение файла как программы»**. Либо в терминале:
`chmod +x PixelManager_*.AppImage`.
</details>

## Первый запуск

1. Убедитесь, что **WB PVZ на этом компьютере хотя бы раз открывали** и заходили
   в свой офис — программа читает ту же базу, что и он.
2. Запустите PixelManager. Базу он находит сам:
   - Windows: `C:\Users\<пользователь>\AppData\Roaming\com.example\wb_point_desktop\wb_point_db.sqlite`
   - Linux: `~/.local/share/wb_point_desktop/wb_point_db.sqlite`
3. Если сверху появилась жёлтая полоса **«База WB PVZ не найдена»** — нажмите
   **«Указать путь»** и выберите файл `wb_point_db.sqlite` вручную.
4. Всё. Данные обновляются сами, как только WB PVZ что-то записывает.

**Закрывать WB PVZ не нужно.** PixelManager никогда не открывает рабочий файл
базы — он делает мгновенную копию и читает её. Поэтому сообщение WB «закройте
другие вкладки» из-за нас появиться не может.

## Обновления

Программа проверяет обновления сама при запуске и показывает окно со списком
изменений — нужно только нажать «Обновить».

| Как установлено | Обновляется само |
|---|---|
| Windows `setup.exe` | ✅ да |
| Linux `.AppImage` | ✅ да |
| Linux `.deb` | ❌ нет — скачайте новый `.deb` и поставьте поверх |
| Windows portable `.exe` | ❌ нет — скачайте новый файл |

Все версии и что в них изменилось — на [странице релизов](https://github.com/Pel1x1/pixelmanager-releases/releases).

## Частые вопросы

**Это безопасно для моего ПВЗ? WB не заблокирует?**
PixelManager работает только **на чтение**: он копирует файл базы WB и читает
копию. Ни одной записи в данные WB, ни одного запроса к серверам WB от нашего
имени. Официальный клиент продолжает работать как обычно.

**Мои данные куда-то уходят?**
Товары, клиенты, ФИО и полные номера телефонов **остаются на вашем компьютере**.
Раз в час владельцу сети уходит сводка по точке: выдачи, отказы, суммы, разбивка
по часам, остатки на складе — и заметки операторов, в которых от номера телефона
хранятся **только последние 4 цифры**.

**Сколько точек можно подключить?**
Сколько угодно. Каждая точка видна в панели владельца отдельно, статистика — и
по точке, и по сети целиком.

**Работает без интернета?**
Да. Весь рабочий функционал — склад, поиск, смена, заметки — локальный.
Интернет нужен только для обновлений и синхронизации с панелью владельца.

**Есть версия для macOS?**
Пока нет: официальный WB PVZ под macOS не выпускается.
